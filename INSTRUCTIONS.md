# Project Instructions: Personal Carbon Footprint Tracker

## Project Overview & Intent
- **What we are building:** A Personal Carbon Footprint Tracker web application that allows users to log daily habits, monitor estimated carbon emissions over time, and visualize their footprint by category.
- **Target Audience / Purpose:** A portfolio web application built with clean, modern React and TypeScript practices.

## Tech Stack & Architecture
- **Framework:** React with TypeScript (Vite bundler)
- **Routing:** React Router (`react-router-dom`)
- **Styling:** Tailwind CSS
- **State Management:** React `useState` hooks for local session data

## Coding Constraints & Rules for AI Agents
- **Type Safety:** Always use existing types defined in `src/types/footprint.ts`. Avoid using `any`.
- **Dependencies:** Do not add new external npm packages without asking first. Prefer native React, CSS, or Tailwind solutions where possible.
- **Explanation:** Explain code changes clearly and provide clean diffs.
- **Modularity:** Keep components small, reusable, and cleanly separated between `components/` and `views/`.
